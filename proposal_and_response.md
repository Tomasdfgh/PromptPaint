# Project Proposal

**Title:** PromptPalette - Paint Inspired Interaction for Steering Text to Image Generation

## Project Description

This project proposes PromptPalette, an interactive prototype that extends the ideas from PromptPaint to explore more lightweight, accessible ways of steering text-to-image generation. The system treats prompts as manipulable visual elements, allowing users to mix, shift, and spatially apply prompts using simple paint-like interactions, while focusing on reducing cognitive load and unpredictability in diffusion models. The project seeks to target a narrow design goal: enabling users to iteratively refine hard-to-verbalize visual concepts through manipulation. The prototype will be implemented using a diffusion model backend and a web-based interface.
